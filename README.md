*Built by Alexutzu under the TreeSoft Proprietary License (TPL)*

## Source layout

- [`src/web/`](src/web/) contains the browser entry point, page controller, view, and firmware registry.
- [`src/firmware/`](src/firmware/) contains firmware-specific runtime files and bundled binaries.
- [`src/shared/`](src/shared/) contains JavaScript utilities shared across firmware versions.
- [`src/payload/`](src/payload/) is reserved for the future Entry4 payload source in C.
